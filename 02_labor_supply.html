수식 풀이 — 수식을 어려워하는 하루가 대신 물어봅니다

실업률의 분모는 왜 전체 인구가 아니에요?

학교 수학으로 보면 중학교 비율과 백분율이에요. 무엇을 분모로 잡느냐에 따라 같은 사람 수도 다른 %가 돼요.

실업률 = U ÷ (E + U) × 100 · 경제활동참가율 = (E + U) ÷ P × 100 · 고용률 = E ÷ P × 100
E취업자: 수입을 목적으로 1주일에 1시간 이상 일한 사람(일시 휴직자 포함)
U실업자: 일이 없고, 일할 뜻이 있고, 지난 4주간 구직했고, 바로 일할 수 있는 사람
P생산가능인구(15세 이상)
비경제활동인구학생·가사·육아·은퇴·구직 단념자(실망실업자)
숫자로 한 번 해 보기처음: 40 ÷ 640 = 6.25%20만 명 구직 포기: 20 ÷ 620 = 3.23%고용률: 600 ÷ 1,000 = 60% (변화 없음)경제활동참가율: 64% → 62%

분모에서 사람이 빠지니까 실업률이 착시처럼 좋아지는 거군요.

2여가와 소비

좋은 것 두 가지 — 무차별곡선과 예산선

모형: U = f(C, L), C = w(T − L) + V예제: 조합 A(400, 100) vs B(250, 150)

주당 112시간(잠자는 시간 빼고)을 일과 여가로 나눠요. 시급 20달러, 근로와 상관없는 소득 320달러가 있다면, 고를 수 있는 조합과 마음에 드는 조합은 어떻게 그릴까요?

이 단계에서 가져갈 한 가지

무차별곡선은 같은 만족을 주는 (소비, 여가) 조합이고, 예산선은 시급과 비근로소득으로 가능한 조합이다. 예산선의 기울기는 −w, 여가 1시간의 기회비용이다.

왜 이 방법을 쓰나

문제 상황

일을 더 하면 돈은 늘지만 쉬는 시간이 줄어요. 둘을 어떻게 저울질할까요?

앞 방법의 한계

"돈이 많을수록 좋다"만으로는 왜 사람들이 하루 종일 일하지 않는지 설명 못 해요.

해법

소비와 여가를 둘 다 좋은 것(재화)으로 보고, 같은 만족을 주는 조합을 곡선(무차별곡선)으로, 가능한 조합을 직선(예산선)으로 그려요.

쉽게 말하면 치킨과 피자를 둘 다 좋아하면 "치킨 2 + 피자 1"과 "치킨 1 + 피자 2"가 똑같이 만족스러울 수 있어요. 지갑이 허락하는 조합 안에서 골라요.

수식 풀이 — 수식을 어려워하는 하루가 대신 물어봅니다

무차별곡선이 왜 휘어 있고, 예산선 기울기가 왜 −w예요?

학교 수학으로 보면 중학교 반비례 그래프 y = k/x와 일차함수예요. U = C × L이면 무차별곡선은 C = U ÷ L이에요.

U = C × L (같은 U → C = U ÷ L) · 예산선 C = w(T − L) + V
무차별곡선우하향·서로 교차하지 않음·원점에 볼록
MRS = C ÷ L여가 1시간을 위해 포기할 마음이 있는 소비(주관적 교환비율)
−w예산선 기울기: 여가 1시간 = 시급만큼의 소비 포기(시장 교환비율)
(T, V)일을 전혀 안 할 때의 점 E(부존점)
숫자로 한 번 해 보기A: 400 × 100 = 40,000 · B: 250 × 150 = 37,500 → A 선호√을 씌우면 200 vs 193.6 (강의노트 표기)예산선 L = 90: C = 20 × 22 + 320 = 760L = 90에서 MRS = 760 ÷ 90 ≈ 8.4 < w = 20 → 더 일하는 편이 이득

곡선은 "내 마음", 직선은 "지갑 사정"이네요. 둘이 만나는 곳을 찾으면 되겠어요.

일상으로 치면

둘 다 좋아하면 하나를 줄일 때 다른 하나를 더 받아야 같은 만족이에요. 많이 가진 쪽은 덜 아까워요.

노동경제학으로는

무차별곡선이 원점에 볼록한 건 한계대체율 체감 때문이에요. 바쁠 때(여가가 적을 때)는 여가 1시간이 매우 소중해 많은 소비를 포기할 수 있지만, 여가가 많으면 1시간의 가치가 낮아져요. 서로 다른 무차별곡선은 교차하지 않고, 원점에서 멀수록 효용이 높아요.

박사

여가 90시간을 골랐어요. 이게 최선일까요?

주판봇 조교

쉬는 시간이 많으니 행복하지!

초파리 조교

MRS 카드와 시급 카드를 비교해 봐. 8.4 대 20이야.

시아

시아예요. 여가를 줄이니 보라 곡선이 더 바깥으로 가요.

하루

여가 1시간의 주관적 가치(8.4달러)가 시장 가격(20달러)보다 낮으면 여가를 팔고(일하고) 소비를 사는 게 이득이에요.

실험 — 예산선 위에서 조합 골라 보기

자세한 풀이 — 그림 두 개 읽기
  1. 무차별곡선: 같은 곡선 위는 같은 만족, 바깥 곡선일수록 높은 만족.
  2. 예산선: 여가 0이면 C = wT + V, 여가 T면 C = V. 기울기 −w.
  3. 예산선 위 점에서 MRS > w면 여가를 늘리고, MRS < w면 여가를 줄여요.

이 단계의 한계 · 어느 점이 가장 좋은지 손으로 찾았어요. 다음 단계에서 공식으로 바로 구하고, 일을 아예 안 하는 경우도 봐요.

업무에 쓸 때 알아 둘 것

뉴스·정책으로 읽으면

"주 4일제 도입" 논의는 근로시간(H)과 여가(L)의 조합을 제도로 바꾸는 이야기예요.

실제로는 근로시간을 마음대로 고르기 어려운 일자리가 많아요.

현장에 옮기면

근무 형태를 설계할 때 같은 연봉이라도 여가가 늘면 만족(효용)이 오를 수 있다는 점을 고려하세요.

3최적 선택

가장 좋은 근로시간 — MRS = w와 유보임금

모형: MRS = w, 코너해예제: w = 20, V = 320, T = 112

효용 U = C × L, 시급 20달러, 비근로소득 320달러, 주당 112시간. 몇 시간 일하는 게 가장 좋을까요? 그리고 시급이 얼마 아래면 아예 일하지 않을까요?

이 단계에서 가져갈 한 가지

효용이 가장 큰 점은 무차별곡선이 예산선에 접하는 곳(MRS = w)이다. 시급이 유보임금보다 낮으면 일하지 않는 코너해가 최선이다.

왜 이 방법을 쓰나

문제 상황

시급 20달러에 비근로소득 320달러, 주당 몇 시간 일해야 가장 만족스러울까요?

앞 방법의 한계

예산선 위를 하나씩 비교하면 시간이 오래 걸리고, 일을 아예 안 하는 경우를 놓치기 쉬워요.

해법

접선 조건 MRS = w와 예산선을 연립해 풀고, 일하지 않는 점 E에서 무차별곡선 기울기(유보임금)를 시급과 비교해요.

쉽게 말하면 마지막 1시간의 휴식이 주는 만족이 그 시간에 벌 돈의 만족과 같아질 때까지 일해요.

수식 풀이 — 수식을 어려워하는 하루가 대신 물어봅니다

C = 20L은 어디서 나왔고, 64시간은 어떻게 나와요?

학교 수학으로 보면 중학교 연립일차방정식이에요. 접선 조건과 예산선 두 식을 함께 풀어요.

MRS = C ÷ L = w → C = wL · 예산선 C = w(T − L) + V → L* = (wT + V) ÷ 2w
MRS = w마음속 교환비율 = 시장 교환비율(접점)
L* · h*최적 여가 · 최적 근로시간 h* = T − L*
코너해L* ≥ T이면 일하지 않음(h* = 0)
유보임금 w_R일하지 않는 점 E에서 MRS = V ÷ T. 시급이 이보다 높아야 일함
숫자로 한 번 해 보기C = 20L, C = 20(112 − L) + 320 = 2,560 − 20L40L = 2,560 → L* = 64, h* = 48시간, C* = 1,280연습: w = 20, V = 0, T = 100 → L* = h* = 50유보임금 = 320 ÷ 112 ≈ $2.86

"마지막 1시간"끼리 비교한다는 게 결국 기울기를 같게 놓는 거였네요!

일상으로 치면

퇴근 직전 1시간을 더 일할지 고민될 때, 그 1시간의 휴식과 그 1시간 벌 돈을 비교해요.

노동경제학으로는

내부해에서는 무차별곡선과 예산선이 접해 MRS = w가 돼요. 일하지 않는 점 E에서 무차별곡선이 예산선보다 가파르면(시급 < 유보임금) 일하지 않는 게 최선인 코너해예요. 유보임금이 높을수록 노동시장에 참여할 가능성이 낮아지고, 비근로소득이 늘면 유보임금이 올라가요. 실제로 임금 수준과 경제활동참가율은 같은 방향으로 움직여요.

실험 — 최적 근로시간과 유보임금

자세한 풀이 — 세 단계
  1. 예산선 세우기: C = w(T − L) + V.
  2. 접선 조건: MRS = w. U = C × L이면 C ÷ L = w → C = wL.
  3. 연립해서 L*를 구하고 L* ≥ T이면 h* = 0(코너해)으로 고쳐요.
  4. 유보임금 = 일하지 않는 점의 MRS = V ÷ T. w > w_R일 때만 일해요.

이 단계의 한계 · 한 시점에서 임금이 주어졌을 때의 답이에요. 임금이 오르면 더 일할까, 덜 일할까? CH03에서 두 효과로 나눠 봐요.

"복권 당첨자 상당수가 일을 그만둔다"는 비근로소득이 늘어 유보임금이 시급보다 높아진 결과로 읽을 수 있어요.

실제 사람의 효용함수는 모두 달라 C × L처럼 단순하지 않아요.
